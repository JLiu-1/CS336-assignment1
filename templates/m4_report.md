# M4 小组报告

## 成员与整合

三位成员、代码来源 commit、整合修改、各自实现和交叉复核工作。

## 正确性

- 阶段验收结果；输入/目标错一位的例子。
- 固定 batch 过拟合初始/最终 loss。
- 连续训练与恢复训练的差异，恢复了哪些状态。
- 梯度累积与一次大 batch 的对照。
- 一个实际排查的问题、证据与修复。

## 短训练

数据/tokenizer 标识、模型配置、训练 token 数、精度、耗时、验证范围、曲线；说明使用的课程预算档。

## 生成

固定 prompt、随机种子、temperature/top-p、生成记录；解释最后位置 logits、EOS 与上下文截断。

## 每位成员的理解

每人说明一段非本人主写的核心代码，以及复核时确认的一个不变量。
